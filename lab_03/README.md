## Запуск

Требуется Python 3.10 или новее. Используется только стандартная библиотека.
Все команды ниже выполняются из каталога `lab_03`.

```bash
python3 -m lab_python_fp.field
python3 -m lab_python_fp.gen_random
python3 -m lab_python_fp.unique
python3 -m lab_python_fp.sort
python3 -m lab_python_fp.print_result
python3 -m lab_python_fp.cm_timer
python3 -m lab_python_fp.process_data data/data_light.json --seed 35
python3 -m unittest discover -s tests -v
```

Каждый файл также запускается напрямую: например,
`python3 lab_python_fp/process_data.py data/data_light.json --seed 35`.
Если путь не задан, программа использует включённый датасет относительно своего
расположения. `--seed 35` делает зарплаты в демонстрации повторяемыми; без этого
параметра они случайны. Зарплаты генерируются по условию и не являются исходными
зарплатами вакансий.

## Решения

| Файл | Содержание |
|---|---|
| `field.py` | Ленивый выбор одного или нескольких полей; `None` и отсутствующие поля пропускаются |
| `gen_random.py` | Генератор целых чисел с включёнными границами |
| `unique.py` | Итератор без дубликатов; сохраняет первое значение и исходный порядок |
| `sort.py` | Сортировка по модулю по убыванию с `lambda` и без неё |
| `print_result.py` | Декоратор печати, сохраняющий результат, аргументы и метаданные функции |
| `cm_timer.py` | Таймер как класс и как генератор с `contextlib` |
| `process_data.py` | Цепочка `f1` → `f2` → `f3` → `f4` с декоратором и таймером |

`Unique` рассчитан на хешируемые значения (числа, строки, кортежи из
хешируемых элементов). Для сравнения строк без учёта регистра применяется
`casefold()`, при этом возвращается исходная строка. `ignore_case=True` следует
описанию и примеру задания: `a` и `A` считаются одинаковыми.
