# Лабораторная работа №1

**ПиКЯП, ИУ5, осень 2026. Рулев К. А., ИУ5-35Б.**

Решение биквадратного уравнения `A*x^4 + B*x^2 + C = 0` тремя способами.
[Официальное условие](https://github.com/ugapanyuk/BKIT_2022/wiki/lab_python_intro).

## Запуск

Нужен Python 3.10 или новее. Используется только стандартная библиотека.
Команды выполняются из каталога этой лабораторной.

```bash
python3 procedural.py 1 -5 4
python3 oop.py 1 -5 4
python3 functional.py 1 -5 4
```

Без аргументов программа запросит все коэффициенты. Можно передать только
первые один или два коэффициента. Некорректный аргумент заменяется вводом
с клавиатуры, остальные корректные аргументы сохраняются:

```bash
python3 procedural.py ошибочный -5 4
```

При запросе введите `1`. Значения `nan`, `inf`, бесконечные и нечисловые
коэффициенты отвергаются. Четыре и более аргумента считаются ошибкой.

## Устройство

- `procedural.py` - решение через функцию и условные операторы.
- `oop.py` - класс уравнения с коэффициентами, свойством дискриминанта и методом решения.
- `functional.py` - чистая функция, выбирающая случаи через `match`.
- `common.py` - общий ввод/вывод, проверка коэффициентов, преобразование `t = x²`.
- `test_lab01.py` - математические проверки и запуск реальных консольных программ.

Все решатели возвращают отсортированный кортеж уникальных действительных
корней. Пустой кортеж означает отсутствие корней, `None` - тождество `0 = 0`.
Учтены случаи `A = 0`, `A = B = 0`, повторные и нулевые корни.

Промежуточные вычисления выполняются в `Decimal` с 50 значащими цифрами,
чтобы большие конечные коэффициенты не вызывали переполнение дискриминанта.
Устойчивая квадратная формула сохраняет малый корень при сильно различающихся
корнях. Вывод ограничен 12 значащими цифрами; это численное решение, не символьное.
