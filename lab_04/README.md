## Запуск

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Команды выполняются из каталога этой лабораторной работы:

```bash
dotnet run
dotnet run -- --test
dotnet run -- --all
```

Первая команда показывает решения, вторая выполняет 67 проверок, третья делает и то и другое. Дополнительные пакеты тестирования не нужны. Первый запуск автоматически восстанавливает стандартные зависимости проекта. Сборка без запуска:

```bash
dotnet build
```

## Соответствие заданию

| Пункт | Реализация в `LabFunctions.fs` |
| --- | --- |
| 1 | `tupledOperations`, `curriedOperations`: сумма, разность и произведение в кортеже |
| 2 | `sumRange`: обычная рекурсия для суммы диапазона |
| 3 | `sumRangeTail`: хвостовая рекурсия с аккумулятором `int64` |
| 4 | `runTrafficLight`: три взаимно-рекурсивных состояния светофора |
| 5 | `applyTupled`, `applyCurried`: передача трёх чисел и лямбды |
| 6 | `makeTriple`, `inferredTriple`: обобщение и вывод конкретных типов |
| 7 | `addThree` и три специализации: сложение `int`, `float`, `string` |
| 8 | `evenPowers`: списковое включение для чётных чисел 1..10 |
| 9 | `squaresIf`, `squaresMatch`: обработка списка через `Head` и `Tail` |
| 10 | `sumOrdinary`, `foldOrdinary`, `zipOrdinary`: вложенные вызовы |
| 11 | `sumPipeline`, `foldPipeline`, `zipPipeline`: оператор `\|>` |
| 12 | `sumComposition`, `foldComposition`, `zipComposition`: оператор `>>` |

В пунктах 10-12 первая и вторая комбинации суммируют квадраты чётных элементов. Третья связывает отсортированные чётные элементы с их квадратами. Порядок значений и дубликаты сохраняются согласно операциям списков.

Обычная рекурсия оставлена для учебного сравнения: на больших диапазонах следует использовать хвостовой вариант. В примерах квадратов и сложения `int` используются небольшие значения; это операции стандартного ограниченного целочисленного типа, а не произвольной точности.

## Файлы

- `LabFunctions.fs` - решения всех пунктов.
- `Program.fs` - консольная демонстрация и аргументы запуска.
- `Tests.fs` - автоматические проверки, включая пустые списки, отрицательные числа, дубликаты, переходы автомата и большой диапазон для хвостовой рекурсии.
- `output.txt` - фактический вывод запуска `--all` на .NET SDK 10.0.404.
- `report.md` - исходник отчёта.
- `output/pdf/report.pdf` - отчёт в PDF.
